# Структура основных директорий проекта

```
apps/
    lampadion-cli
    lampadion-host
    lampadion-gui
    lampadion-launcher
    lampadion-website
crates/
    lampadion-assets (graphics, styles, sound, for gui and website)
    lampadion-binding
    lampadion-compose
    lampadion-core
    lampadion-config
    lampadion-db
    lampadion-extensions
    lampadion-ipc
    lampadion-keyboard
    lampadion-layout
    lampadion-model
    lampadion-modes
    lampadion-scripting
    lampadion-search
    lampadion-ui (reusable components for gui and website)
    lampadion-unicode
    lampadion-l10n
data/ (.ron)
    characters/
    simulated_layout/
        latin/ (qwerty.ron, dvorak.ron etc.)
        cyrillic/ (<йцукен>jcuken.ron etc.)
        hellenic/ (<koppa-digamma-epsilon-rho-tau-upsilon>qwerty.ron)
    binding/
locale/ (.ftl)
    <ISO 639-ISO 3166>/ (generated.ftl, alchemy.ftl etc.)
    <ISO 639-ISO 3166>.ftl
```

## Задачи Apps

- Лаунчер выполняет роль входной точки, поднимает хост и dioxus GUI
- Хост отвечает за всю логику приложения, общается с dioxus GUI для передачи тому данных
- GUI отвечает за отрисовку как главного окна, так и вспомогательных окон — селектор режимов, подсказка ввода (IME/Compose) и прочее
- Вебсайт просто сайт презентация, не включается в само приложение
- Статус CLI пока спорен

# Структура релизного проекта

```Windows
Lampadion/
    assets/
        graphics/
        styles/
        sounds/
    bin/
        host.exe
        cli.exe
        gui.exe
    data/ (.ron)
    locale/ (.ftl)
    extensions/
    user/
        profile-<profile name>/
            bindings/ (.ron)
                default.ron (always enabled, no switch required)
            compose/ (.ron), (.XCompose)
                default.ron (always enabled, no switch required; used by User-Defined sequences)
            simulated_layout/ (.ron)
            config.ron
            favorite.ron
            extensions.ron
        profile.ron
    lampadion.exe # Launcher
```
