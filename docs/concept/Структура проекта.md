# Структура основных директорий проекта

```
apps/
    lampadion-cli
    lampadion-daemon
    lampadion-gui
crates/
    lampadion-binding
    lampadion-compose
    lampadion-core
    lampadion-config
    lampadion-db
    lampadion-extensions
    lampadion-keyboard
    lampadion-layout
    lampadion-model
    lampadion-modes
    lampadion-scripting
    lampadion-search
    lampadion-unicode
    lampadion-l10n
data/ (.ron)
    characters/
    simulated_layout/
        latin/ (qwerty.ron, dvorak.ron etc.)
        cyrillic/ (<йцукен>jcuken.ron etc.)
        hellenic/ (<koppa-digamma-epsilon-rho-tau-upsilon>qwerty.ron)
    binding/
locale/ (.ftl)
    <ISO 639-ISO 3166>/ (generated.ftl, alchemy.ftl etc.)
    <ISO 639-ISO 3166>.ftl
frontend/
    lampadion-gui/ (Vue 3 Project)
```

# Структура релизного проекта

```Windows
Lampadion/
    assets/
        images/
        sounds/
    bin/
        daemon.exe
        cli.exe
        gui.exe
    data/ (.ron)
    locale/ (.ftl)
    frontend/
        gui/ (Vue 3 Project)
    extensions/
    user/
        profile-<profile name>/
            bindings/ (.ron)
                default.ron (always enabled, no switch required)
            compose/ (.ron), (.XCompose)
                default.ron (always enabled, no switch required; used by User-Defined sequences)
            simulated_layout/ (.ron)
            config.ron
            favorite.ron
            extensions.ron
        profile.ron
    lampadion.exe
```
